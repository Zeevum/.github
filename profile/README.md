# Zeevum
**Self-hosted messenger. Свой сервер, свои данные, открытый код.**

## Что это
Мессенджер, который можно хостить самому:
- Поднятие сервера на VPS
- Подключение клиентом
- Общение без посредников

Без облаков, без аккаунтов "*где-то там*"

Ваша база — ваши ключи и ваши правила

## Репозитории
| Репозиторий |	Что это |
|---|---|
| Zeevum-server	| Сервер: Rust + SQLite + TLS. Установка одной командой (systemd-инсталлер) |
| Zeevum-android	| Клиент: Rust + Slint. Windows (*временно*), Android в разработке |
| Zeevum-protocol	| Протокол: общий протокол сервера и клиентов |

## Статус
***Проект в разработке***

Уже работает:
- Регистрация
- Друзья
- Приватные чаты
- История
- Статусы прочтения

В планах:
- Доставка оффлайн-сообщений
- Групповые чаты
- Android-клиент
- E2EE

***Пока что не рекомендуется как основное средство связи — пока только для тестирования.***

## Быстрый старт
1. VPS с Linux (Рекомендуется Ubuntu 22.04+) и домен с TLS-сертификатом (Let's Encrypt)
2. Установить [сервер](https://github.com/Zeevum/Zeevum-server)
3. Собрать или скачать [клиент](https://github.com/Zeevum/Zeevum-android)
4. Указать адрес сервера в настройках клиента
